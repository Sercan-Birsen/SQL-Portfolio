# Vendor Payment Analysis

## Project Overview

This project analyzes vendor payment data using SQL and a relational database.

The objective is to answer common business questions related to vendor performance, payment activity, and country-level reporting.

---

## Database

The project uses three related tables:

- **Vendors**
- **Payments**
- **Vendor Contacts**

---

## Business Questions

- Which countries have the highest payment volume?
- Which vendors have not received any payments?
- Which vendors are above the average total payment?
- Which countries generate the highest payment totals?
- Which active vendors have not received payments in the last 12 months?
